# Pipeline formal · reservado

Esta carpeta se conserva para código reutilizable del pipeline principal.
Actualmente no contiene módulos implementados: el trabajo ejecutable vive en
[understanding/](../understanding/README.md).

Incorporar aquí una implementación solo cuando esté comprendida, validada y sea
necesaria para un experimento formal. Documentar entradas/salidas y dimensiones,
añadir las pruebas relevantes en `../tests/` y conservar una referencia verificable.
No migrar automáticamente los laboratorios ni crear abstracciones por anticipado.
